# K&C | Digital Architect & Cultural Collective

A premium, cinematic portfolio for **Kelsey & Company**, featuring high-impact storytelling, experiential brand activations, and executive brand management.

## 💎 Design Philosophy
Built with a "Cinema-First" approach, the platform utilizes:
- **Dynamic Portals**: A custom-engineered SVG diamond portal transition.
- **Micro-Interactions**: Magnetic buttons and scroll-triggered reveal animations.
- **Premium Audio**: A custom-built "Radio Studio" player for audio-first deliverables.
- **Fluid Layouts**: Responsively designed for high-end desktop and mobile experiences.

## 🛠️ Technical Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS 4.0
- **Animations**: Framer Motion
- **3D/Particles**: React Three Fiber + Custom GLSL
- **Asset Management**: Cloudinary (Dynamic optimization)
- **Deployment**: Vercel

## 🚀 Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Build for production: `npm run build`
